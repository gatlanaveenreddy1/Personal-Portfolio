# Gatla Naveen Reddy — Personal Portfolio Website

A responsive, glassmorphic personal portfolio website for **Gatla Naveen Reddy** (B.Tech ECE Student & Web Developer).

---

## 🚀 Features

- **Hero Section**: Typewriter text effect, tech badges, and social links.
- **Theme Toggling**: Dark and Light theme switcher with local storage persistence.
- **Technical Skills**: Visual skill meters across Languages, Web Tech, DSA, AI & LLM Applications, and Engineering Tools.
- **Training & Courses**: Integrated NxtWave CCBP 4.0 Learning Journey (`https://learning.ccbp.in/my-journey?tab=growth_cycles`).
- **Projects Showcase**: Categorized project cards covering Web Development and ECE & Simulation.
- **Certifications & Coding Profiles**: Verified credentials and coding platform stats (LeetCode, HackerRank, CodeChef, GeeksforGeeks).
- **Contact Form**: Direct email sending using FormSubmit AJAX integration (`gatlanaveenreddy1@gmail.com`).

---

## 🛠️ Tech Stack

- **HTML5**: Semantic Markup
- **CSS3**: Custom Properties, Flexbox, CSS Grid, Glassmorphism Animations
- **JavaScript (ES6+)**: DOM Manipulation, IntersectionObserver API, Fetch API
- **Fonts & Icons**: Google Fonts (Outfit & Plus Jakarta Sans), FontAwesome 6
